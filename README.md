A full-stack personal resume, portfolio, and guestbook application built with Node.js, Express, EJS, and MySQL.

## Project Description

This web app serves as Kelley Castillo's professional online presence. It includes:

- **Resume page** – Work experience, technical skills, and education
- **Portfolio page** – Showcase of SDEV 301, SDEV 305, and internship projects with screenshots, tech stack, and GitHub links
- **Contact / Guestbook form** – Visitors can leave their info, optionally subscribe to a mailing list; includes both client-side and **server-side validation**
- **Confirmation page** – Shows a summary of the submitted info
- **Admin dashboard** – Lists all submissions from the MySQL database with DataTables sorting/search
- **Responsive navigation** – Sticky top nav with hamburger menu on mobile, visible on every page
